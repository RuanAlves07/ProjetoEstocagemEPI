Integração com o Microsoft Forms

O Power Automate envia cada resposta do formulário para o sistema, que cria o card do pedido automaticamente.

Montando o fluxo no Power Automate

  1. Gatilho: Microsoft Forms → Quando uma nova resposta é enviada (escolha o formulário) e, em seguida, a ação Obter detalhes da resposta.
  2. Ação HTTP (conector premium): método POST, URL e cabeçalhos abaixo.
  3. Cabeçalhos: Content-Type: application/json e X-API-Key: (a chave acima).
  4. Corpo (JSON): preencha cada valor com a resposta correspondente do formulário (conteúdo dinâmico):
{
  "id":          "ID da resposta",
  "nome":        "Nome",
  "local":       "Local",
  "motivo":      "Motivo",
  "vestimento":  "Vestimento",
  "epi":         "EPI",
  "sapatao":     "Sapatão",
  "camiseta":    "Camiseta",
  "calca":       "Calça",
  "observacao":  "Observação"
}

Só nome é obrigatório. O id evita pedido duplicado se o fluxo for reenviado. Perguntas de múltipla escolha são aceitas (o sistema separa os itens por “;” ou vírgula; “2x Luva G” vira quantidade 2).

Teste do terminal:

curl -X POST {{ url_api }} \
  -H "Content-Type: application/json" -H "X-API-Key: {{ chave }}" \
  -d '{"nome":"Fulano","local":"Obra A","motivo":"Reposição","epi":"Luva G; Óculos","sapatao":"Bota 40"}'

Alternativa sem conector HTTP Premium (via planilha Excel do Forms)

Se sua licença do Power Automate não incluir o conector HTTP (Premium), você pode usar a ação padrão Excel Online (Business) → Executar script (Office Script) na planilha onde o Forms grava as respostas, lendo exatamente as colunas H a P:

  • Coluna A: ID da resposta
  • Coluna H: Nome · Coluna I: Local · Coluna J: Motivo
  • Coluna K: Vestimento · Coluna L: EPI · Coluna M: Sapatão · Coluna N: Camiseta · Coluna O: Calça
  • Coluna P: Observação

Também é possível exportar a planilha do Forms como .csv e importar direto em Pedidos → Importar planilha do Forms (CSV).

Como cada resposta vira item de estoque

Vestimento, EPI, Sapatão, Camiseta e Calça viram linhas do pedido. O sistema compara o texto com o nome dos EPIs cadastrados (ignora acentos e maiúsculas; para Camiseta “M” tenta também “Camiseta M”). O que não reconhecer aparece como identificar: a pessoa do almoxarifado escolhe o EPI uma vez e o sistema lembra para os próximos pedidos. Respostas como “Não” ou “Nenhum” são ignoradas.
